# Bank Management System

A console-based Bank Management System built with Python to simulate basic banking operations.

##About the Project

This project allows users to perform basic banking operations such as depositing money,
withdrawing money, checking their balance, and viewing transaction history.

The main purpose of this project was to strengthen my understanding of Core Python and 
Object-Oriented Programming while building a practical application.

## 🚀 Features

- Create a bank account
- Deposit money
- Withdraw money
- Check current balance
- View transaction history
- Save transactions to a file
- Validate transaction amounts
- Handle insufficient balance
- Custom exception handling
- Interactive console menu

##Technologies Used

- Python 3
- File Handling
- Object-Oriented Programming
- Exception Handling
